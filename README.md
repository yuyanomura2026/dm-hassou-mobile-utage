# DM発送.net スマホ用UTAGEページ

`https://dmhassou.info/` のデザイン・コピー・掲載順・既存画像をできるだけ保ったまま、スマートフォン用の1カラムHTMLへ調整したページです。

## 方針

- 元ページの青・赤を基調としたデザインを維持
- 元ページのロゴ、見出し画像、訴求画像、お客様の声を再利用
- PC向けの横並び要素を縦積みへ変更
- 390px幅で横スクロールが発生しないよう調整
- 電話・見積もりボタンを画面下部へ固定
- CSSはHTML内へ内包し、JavaScriptやビルド作業は不要

## ファイル

- `index.html`：UTAGE用HTML本体
- `assets/dm-hassou-logo.gif`：ヘッダーロゴ
- `assets/original/`：元ページから取得したスマホ用・既存画像

## UTAGEへの設置

1. GitHub公開後、`index.html` 内の画像パスを公開URLへ置換します。
2. `index.html` を開いて全文をコピーします。
3. UTAGEのカスタムHTMLブロックへ貼り付けます。
4. 電話ボタンと見積もりボタンの遷移を確認します。

## 注意

実績数値、最短発送条件、電話番号、営業時間は元ページの掲載内容を反映しています。公開前に最新情報と一致しているかご確認ください。
